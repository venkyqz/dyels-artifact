# Retained DYELS storage analysis

- `types.dl` contains native type and layout recovery rules.
- `storage_eval.dl` includes memory/storage analysis and exports native storage
  declarations and proxy classifications.
- `reentrancy_guards.dl` supplies guard recognition used by `storage_eval.dl`.

Remora's native export adapters live in `../gigadall/`. Provenance and licenses
are recorded in `../../SOURCE.md` and the repository license files.
